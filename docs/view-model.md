# Engine view contract

Source: T-11 and NFR-006/009. All commands accept the current opaque LifeState from the previous result. The browser reads the following selectors.

| API                                                      | Public data                                                                                                                                                                                                                                                                                                               |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| getAuthorView(state)                                     | Seed, last confirmed day, phase, pen name, displayed age, motive, route, job, home, eight ability scores, four condition scores, career indicators and special states. Scores are 0–100. Daily time is in 30-minute slots.                                                                                                |
| getWorkViews(state), getWorkView(state, id)              | Independent work ID, title, genre, material, tags, platform, model, lifecycle state, mask, chapter/stock counts, quality, readers, exposure channels, revenue and original ending record. Reader displays use integer counts, money uses won. Daily new readers are distinct from today’s views and latest-chapter views. |
| getPending(state)                                        | Instance ID, candidate day, public event text, optional fixed target title, valid choice IDs and labels, public offer terms. The author’s last confirmed day stays fixed until choose succeeds.                                                                                                                           |
| getEventLog(state, range?), getDailySummary(state, day?) | Recent public events and atomic day summaries. The engine retains a compact daily archive and eligibility history even after verbose display entries expire.                                                                                                                                                              |
| getAptitudeView(state)                                   | Genre/material/tag/schedule/platform, UNKNOWN/GUESS/CERTAIN, public grade and evidence count.                                                                                                                                                                                                                             |
| getContractViews(state), getLedgerView(state)            | Public contract terms and status, ledger entries, accrued and paid totals, cash/debt. All monetary values are integer won.                                                                                                                                                                                                |

createLife(seed) returns the day-zero origin choice. advance(state, days) stops before an unresolved choice, returning the new state and stopped reason. choose(state, eventInstanceId, choiceId) closes the pending day or returns an error with the original state. serialize/deserialize round-trip state at day boundaries and choice waits. The web storage adapter owns IndexedDB and file I/O.

Visual development can reproduce the day-zero choice with seed 42 and choose the first option. The implemented browser test advances this same life through day 32 and checks separate work panels. The CLI and engine tests can reproduce longer runs.
